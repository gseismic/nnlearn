# PLAN-052：将 README 收敛为双语使用教程

## 目标

将仓库主页 `README.md` 改为英文使用教程，并提供简体中文 README 链接。README 仅保留安装、常见 API 使用和运行示例的步骤。

## 范围

1. 将 `README.md` 改为英文，并在顶部提供简体中文版本链接。
2. 新增 `README.zh-CN.md`，提供对应的中文使用教程和返回英文版的链接。
3. 教程覆盖安装、Tensor 运算、自动微分、神经网络训练、批数据加载和运行仓库示例。
4. 移除项目定位、设计文档索引、迁移记录和更新日志等非使用教程内容。

## 实施与检查

1. 根据现有源码和可运行示例核对公开 API 写法。
2. 编写英文主页与对应中文 README。
3. 检查 Markdown 链接，执行 README 中 Python 示例的 API 冒烟验证，并复核 diff。
4. 添加结果记录，以中文提交信息提交并立即推送。

## 验收标准

- `README.md` 为英文，正文只包含使用教程，并链接到 `README.zh-CN.md`。
- 中文版链接能返回英文 README，教程步骤与英文版一致。
- 教程 API 与当前实现一致，示例可运行，本地 Markdown 链接有效。
