## 验收标准

1. 将 `Parameter` 或 `Module` 赋给模块属性后能递归枚举参数，并可清理梯度、导出和载入状态。
2. `Linear` 前向符合 `(N, in_features) @ (in_features, out_features) + bias`，激活函数梯度经过自动微分。
3. MSE 与交叉熵可对 `mini_tensor` 反向；交叉熵使用稳定的 log-sum-exp。
4. SGD 只更新有梯度的参数，支持训练前清理梯度。
5. DataLoader 可顺序/随机采样、分批，并按配置处理不完整末批次。
6. 线性回归误差显著下降；合成三分类 MLP 达到稳定高精度。
7. 保存并载入 MLP 后，相同输入的 logits 一致。
8. 七个示例脚本可运行，`git diff --check` 通过，结果文档记录实际输出和限制。
