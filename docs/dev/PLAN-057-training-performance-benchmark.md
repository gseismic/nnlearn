# PLAN-057：新增 nnlearn 与 PyTorch 训练性能对照示例

日期：2026-10-01

## 背景

仓库已有 PyTorch 风格训练兼容示例和单步数值对照，但没有同时比较训练速度与训练结果的端到端示例。读者需要一个可重复运行的例子，观察同一工作负载在 `nnlearn` 和 PyTorch 上的耗时、吞吐量及最终模型指标。

## 目标

1. 新增一个同时加载 `nnlearn` 与 PyTorch 的性能对照脚本。
2. 两边使用同一份合成分类数据、同一 MLP 初始参数、同一批次顺序、同一优化器超参数和训练步数。
3. 分开计时预热与训练，并报告多次运行的中位数耗时、步/秒、样本/秒、最终 loss 和 accuracy。
4. 默认在 CPU 上对照；可显式选择 CUDA，并在两边都支持 CUDA 时运行。计时边界同步设备，避免异步执行造成误报。
5. 更新训练机制教程，链接新示例，并说明指标范围和运行命令。

## 实施步骤

1. 编写 `examples/704_compat_training_performance_benchmark.py`：
   - 使用固定随机种子构造小型多分类数据与共享初始 MLP 参数。
   - 预先准备相同批次，计时范围只包含前向、损失、反向和 SGD 更新。
   - 支持 `--device`、`--steps`、`--warmup` 和 `--repeats` 参数。
   - 输出环境、工作负载、两套框架的性能指标，以及 `nnlearn / PyTorch` 耗时比。
   - PyTorch 未安装或选定设备不可用时，给出可理解的退出信息。
2. 更新 `docs/tutorial/torch-training-mechanism-20260929.md`，补充新基准的运行方式和解释范围。
3. Review 代码与文档，运行示例核验两条训练路径，修复执行中发现的问题。
4. 新增本计划对应的 OUTCOME 文件，记录实际改动和验证结果。

## 验收标准

- 默认 CPU 命令可在同一进程中完成两边对照，无需下载数据。
- CUDA 模式在两种实现均报告 CUDA 可用时才开始运行。
- 每边使用相同的模型初值、训练数据、批次、训练步数和 SGD 学习率。
- 计时包括预热后的训练循环；CUDA 计时前后同步；数据构造、模型创建和最终评估不计入训练耗时。
- 输出 median elapsed time、steps/s、samples/s、loss 和 accuracy，并清楚注明数据规模与训练配置。
- 示例文档说明这是该 MLP 与当前运行环境的基准，不代表通用性能结论。
- `git diff --check` 通过；示例实际运行完成。
