# PLAN-048 编写 CNN 与 Transformer 进阶篇

日期：2026-09-29

## 背景

前三篇已经用 NumPy 实现了标量自动微分、基础 Tensor 和 MLP 训练。下一步沿目录规划进入 CNN 与 Transformer，让读者看到四维图像张量和序列注意力如何进入训练闭环。

## 目标

1. 完成第 18、19 章，循序解释卷积/池化和自注意力/Transformer 编码器。
2. 在教学框架中实现二维卷积、最大池化、Embedding、多头缩放点积注意力和最小编码器层，并保留可手读的前向与反向公式。
3. 用本地合成数据分别运行 CNN 和 Transformer 分类示例，不依赖数据下载。
4. 更新第四篇入口、全书目录、配套代码导航与阶段结果记录。

## 实施范围

- 新增 `book/04-进阶模型与运行时/18-卷积池化与CNN.md`、`19-注意力与Transformer.md`。
- 新增 `book/代码/04-进阶模型与运行时/` 的两个章节示例和配套模块。
- 扩展 `mini_nn`，增加二维卷积/池化/展平、Embedding、多头注意力、LayerNorm 和编码器层。
- 用固定种子合成小数据验证分类训练趋势；脚本不得要求下载真实数据或 CUDA。
- 不实现卷积的任意维数/分组/dilation、池化的复杂边界策略、Transformer mask/dropout/位置编码生态或性能优化。
- 不新增测试套件；运行章节示例并手工复核梯度公式、形状和文档链接。

## 验收标准

1. Conv2d 接受 NCHW 输入，支持步幅与对称 padding，输出形状正确，输入/权重/偏置梯度可反传。
2. MaxPool2d 保存最大值位置并把梯度回传到对应输入位置；Flatten 保持 batch 轴。
3. Embedding 根据整数 token 取表，并在反向时将重复 token 的梯度累加到对应行。
4. 多头注意力对 Q/K/V 执行缩放点积、稳定 softmax 与上下文聚合，梯度形状正确。
5. CNN 和最小 Transformer 分类示例均可运行，损失下降并在简单合成任务上达到高准确率。
6. `git diff --cached --check` 与书稿相对链接复核通过，结果文档记录真实运行输出和实现限制。

## 非目标

1. 不要求复现仓库完整 MNIST CNN 或完整 Transformer API。
2. 不把 NumPy 教学实现描述为高性能或 PyTorch 兼容实现。
3. 设备后端与 PyTorch 数值对照留给后续章节 20、21。
