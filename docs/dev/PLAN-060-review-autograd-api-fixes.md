# PLAN-060：修复完整仓库 Review 的自动微分与接口问题

## 目标

逐项复现用户提供的 13 条 Review，修复成立的问题，防止合并损失漏梯度、梯度清零异常、索引形状错误及精度转换错误。

## 实施范围

1. 将可复用的 MSELoss、CrossEntropyLoss 与每次调用的 Function 节点分离；MSE 反向使用原 Tensor 运算以支持高阶导数。
2. 首次保存累积梯度时克隆为独立可写存储，保留 create_graph 所需的依赖。
3. Gather 前向及 Scatter、ScatterAdd 反向按 index.shape 构造坐标，避免广播非索引维度。
4. Module.to 的精度转换保留整数、布尔缓冲区类型；优化器恢复状态时对齐参数设备及 dtype。
5. 修复 Tensor 创建接口的形状参数展开、sum/mean 的位置参数顺序、单元素 item/bool 行为。
6. 修复零次幂梯度、强弱输出引用的统一读取，以及全局 argmax 的 keepdim。
7. 训练性能基准显式统一两个框架的模型精度为 float32，并更正历史基准结果中的精度说明，避免误用旧耗时比。

## 实施步骤

1. 阅读相关实现与既有测试，新增回归用例并在修复前运行，确认每条问题的失败证据。
2. 按上述范围实施；如范围或方案变化，先更新本计划。
3. 复核梯度存储所有权、高阶导数依赖、接口兼容性、索引坐标及 dtype 传递路径。
4. 运行新增回归测试、CPU 全量测试与小规模训练基准；环境允许时验证 CUDA。
5. 编写对应 OUTCOME 文档，记录复现、变更、测试结果与限制。
6. 以中文详细提交，记录计划与结果文件路径，提交后立即推送。

## 验收标准

- 13 条问题均有可核对的复现与修复依据。
- 新增回归覆盖重复调用损失、独立梯度清零、MSE 二阶导、部分维度索引、状态 dtype、Tensor 接口及输出引用配置。
- CPU 全量测试通过；基准两边参数与训练输入均为 float32，能完成训练。
- git diff --check 通过，计划和结果文档纳入提交并推送。
