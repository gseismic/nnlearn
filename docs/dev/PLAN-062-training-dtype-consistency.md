# PLAN-062：常用训练运算的精度一致性修复

## 目标与依据

用户显式选择 float32 后，常用运算和连续优化步骤必须保持该精度。修复前已复现 mean、乘 Python 标量、平方、sigmoid，以及 tanh、sqrt、极值规约导致的梯度或参数升精度；CPU 基线为 410 passed。

设计：`docs/design/dtype-20261024-training-consistency.md`。

## 实施范围

1. 在 Function 入参包装时区分原生 Python int/float 常量与显式 Tensor，常量沿用浮点上下文 dtype；bool、NumPy 标量/数组和无浮点 Tensor 上下文保留原规则。
2. 在自动微分的回传边上通过可微转换对齐浮点输入梯度 dtype，兼顾显式混合精度、广播还原和梯度累积；建图时缓存输入 dtype，兼容 linear 释放中间 data 的行为。
3. 修复 sum/mean 与常用激活、算术的精度传递；mean 直接求均值并在 float16 反向中使用 float32 归一化。极值掩码与计数使用 Tensor 运算，避免计数升精度和切断上游高阶依赖。
4. 补充对照、边界、高阶及连续多步训练回归，覆盖 SGD、MomentumSGD、Adam、AdamW 的输出、梯度、参数、内部状态和序列化状态 dtype；验证恢复后继续训练。
5. 兼容复查增补：NumPy 1.24.4 实测零维 sigmoid/ReLU 前向、四种优化器的零维参数和状态仍会提升精度。对数值前向内部 Python 常量以及优化器更新系数显式按上下文转换，保持更新公式和 Adam 偏差修正计算次序；增加 NumPy 1.x/2.x 验证。

## 实施步骤

1. 写入设计与本计划，自查规则和范围；新增回归并在修复前执行，记录失败证据。
2. 按设计修复共用入口和规约公式。方案或范围调整时先更新本计划。
3. 逐项复查：显式 dtype 不被常量规则覆盖、整数和 bool 行为不变、零维与设备行为一致、回传转换保留高阶依赖、半精度不发生中间溢出。
4. 运行新增回归、CPU 全量测试及 float32 训练基准；有 CUDA 时补充设备验证。发现问题则修复并再次复查及验证。
5. 生成 `docs/dev/PLAN-062-training-dtype-consistency-OUTCOME.md`，创建历史索引 `docs/dev/INDEX.md` 并追加本计划与结果映射，记录验证和环境限制。
6. 中文详细提交，逐条说明变更并列出设计、计划和结果文档路径，提交后立即推送。

## 计划自查

- 已区分常量推断、显式 Tensor 提升与回传梯度三个层次，不通过优化器末尾转换掩盖精度错误。
- 高阶求导验证覆盖上游依赖和类型转换；大型半精度均值单独检查归一化与累加，防止引入 PLAN-061 同类回归。
- 新测试按行为对照和训练闭环组织，不扩展公开 API，不重写整数或复数类型系统。

## 验收标准

- float32 的 x.mean()、(x * 2).sum()、(x ** 2).sum()、x.sigmoid().sum() 的输出、梯度、训练后参数均为 float32。
- 基础算术、规约和常用激活的数值及一阶/高阶梯度对照正确，显式混合精度规则有回归约束。
- 连续训练及优化器状态保持预期 dtype，恢复后可继续训练。
- 原有 410 项测试及全部新增回归通过，训练基准通过，git diff --check 通过，提交和推送完成。
