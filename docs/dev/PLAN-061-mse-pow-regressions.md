# PLAN-061：修复 MSE 半精度归一化与数组指数回归

## 目标

修复提交 219ad46 复审确认的两个 P2 回归：较大的 float16 张量计算 MSE 时梯度清零，以及数组指数在反向传播中触发布尔判断异常。

## 实施范围

1. MSE 均值反向对 float16 使用 float32 中间计算，避免元素数量转换为半精度后溢出；最终梯度恢复原精度，保留广播还原和高阶求导依赖。
2. Pow 区分标量与数组指数，数组中的零指数逐元素处理，避免零底数处计算负次幂；数组指数随输入设备处理，广播后的梯度还原到输入形状。
3. 新增针对性回归测试，覆盖大尺寸 MSE、精度保持、二阶导，以及数组指数、混合零指数、广播和高阶导。

## 实施步骤

1. 新增回归并在修复前运行，记录失败证据。
2. 完成两处修复，复核 dtype、设备、广播以及计算图依赖；方案调整时先更新本计划。
3. 运行新增测试、CPU 全量测试和 float32 训练基准；CUDA 可用时补充设备验证。
4. 编写对应 OUTCOME 文档，记录代码复核和验证结果。
5. 中文提交中逐条说明变更并列出计划、结果路径，提交后立即推送。

## 验收标准

- 100000 个 float16 的 1 对零目标计算默认 MSE 时，梯度约为 2e-5，并保持 float16。
- x=[2,3]、指数=[2,3] 能正常反向，梯度为 [4,27]。
- 混合零指数在零底数处不产生无效负次幂；广播数组指数的梯度形状和数值正确。
- 一阶和二阶梯度保持预期，CPU 全量测试与训练基准通过。
- 工作区变更完成提交及推送，明确记录 CUDA 验证限制。
