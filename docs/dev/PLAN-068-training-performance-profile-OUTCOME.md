## 已确认的结果

1. **额外梯度计算**：第一层输入无需梯度时仍计算输入梯度。二维按需求反向探针将每步 MatMul 从 6 次降至 5 次；固定 CPU 亲和性、单线程的较大 MLP 中位耗时由 11.6177 降至 8.7909 ms/步，减少 24.33%。
2. **CUDA 细碎运算**：小 MLP 每步 nnlearn/PyTorch 分别约 82/24 个 kernel，交叉熵前向分别为 34/2 个。nnlearn 每步两次布尔标量读回，仅 2 字节，但主机复制 API 成本明显高于设备搬运时间。
3. **矩阵乘法包装开销**：CUDA 二维 dot 路径的多组临时对照表现出收益；CPU 较大矩阵存在回退，不能全局替换。
4. **环境干扰**：检测到其他 GPU 任务和较高 I/O 压力，扩展组出现显著离群值。保留全部原始数据，不把当前倍率、profile 总耗时或 GPU 时间线空隙解释为全库稳定性能结论。

统一 6 线程、100 步预热、1000 步训练、7 次重复的工作站观测中，小 MLP CPU/CUDA 耗时比分别约 2.13/6.69 倍，较大 MLP 约 2.05/6.42 倍；实际范围和环境限制见报告。未取得独占 GPU 的发布级性能验收。
