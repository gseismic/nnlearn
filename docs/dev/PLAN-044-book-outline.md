# PLAN-044《自己动手实现 PyTorch》目录规划

日期：2026-09-29

## 背景

仓库已有 `torch_1k` 教学实现，覆盖 Tensor、自动微分、神经网络模块、优化器、数据加载和训练示例。现有教程主要帮助读者理解既有代码与训练流程；新书需要把这些内容重新组织成从简单概念逐步构建框架的学习路线。

## 目标

1. 在 `book/` 建立中文书稿目录和读者入口。
2. 按“标量求导 → 张量与自动微分 → 神经网络训练 → 进阶模型与运行时”安排章节。
3. 为各部分标出目标、章节顺序及对应的现有源码入口，便于后续逐章写作。
4. 明确本轮只规划目录，不撰写章节正文或新增框架实现。

## 实施范围

- 新增 `docs/design/book-20260929-outline.md`，说明写作对象、递进原则、章节依赖和源码映射。
- 新增 `book/README.md` 和 `book/目录规划.md`，作为书稿入口和完整目录。
- 在 `book/` 下为各篇、阅读指南和附录建立目录说明页，并预留代码示例目录说明。
- 新增本计划对应的结果文档。

## 验收标准

1. 第一部分从一个标量开始，读者可以先理解导数、计算图和反向传播，再进入多维 Tensor。
2. 章节顺序能逐步走到线性回归、mini-batch、MLP，并把 CNN、Transformer、设备后端放在进阶部分。
3. 书稿目录位于 `book/`，章节对应现有源码和示例的关系清楚。
4. 清楚说明本项目是用于理解训练机制的小型教学实现，不承诺覆盖完整 PyTorch。
5. 完成文档差异复核与 `git diff --check`；本轮不运行测试套件。
6. 创建 OUTCOME，按 `AGENTS.md` 使用中文提交并立即推送。

## 实施步骤

1. 创建本计划。
2. 编写目录设计和 `book/` 入口、各部分目录说明。
3. 复核学习顺序、源码映射、链接及本轮范围。
4. 写入结果文档，提交并推送。

## 非目标

1. 本轮不写具体章节内容、习题答案或配套实现代码。
2. 不为了书稿调整 `torch_1k` 的 API 或代码结构。
3. 不宣称书稿覆盖完整 PyTorch 或能够替代 PyTorch。
