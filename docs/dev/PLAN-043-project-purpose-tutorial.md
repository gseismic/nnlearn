# PLAN-043 项目定位与训练机制对照教程

日期：2026-09-29

## 背景

PyTorch 已是成熟的深度学习框架。本项目若持续以“补齐 PyTorch API”为主线，很难解释用户为什么还要使用它。仓库已有反向自动微分实现、CPU/CUDA 后端、训练示例和与 PyTorch 对照的测试，适合明确定位为一套可运行、可阅读、可对照的训练机制教材。

现有公开说明仍称“1000 行实现”，而 2026-06-24 路线图把整体控制在 3000 行作为建议；截至本计划日期，`nlearn` Python 文件按 `wc -l` 统计为 4716 行。旧说法与当前项目规模不符，也容易让读者把有限 API 误认为通用替代品。

## 目标

1. 明确项目服务对象：想理解张量自动微分和训练链路的 Python / PyTorch 学习者。
2. 明确项目用途：阅读实现、运行例子、修改算子，并用 PyTorch 对照结果。
3. 新增一个单步线性回归对照程序，用相同数据和参数比较前向结果、损失、参数梯度及 SGD 更新结果。
4. 新增中文教程，逐步解释 Tensor、算子、计算图、反向传播、梯度和参数更新，并说明兼容范围与已知差异。
5. 更新 README 和设计路线图，移除过时的行数宣传及宽泛的“直接替换”表述。

## 实施范围

## 验收标准

1. 教程和 README 使用中文，结论与仓库当前 API 范围相符。
2. 对照例子为两边提供相同输入、目标、初始参数和学习率；损失、梯度与更新后参数可直接对照。
3. 示例依赖 PyTorch 作为可选参考实现；缺少 PyTorch 时有明确安装提示。
4. 明确声明本项目不追求完整 PyTorch 兼容性或性能替代，并标出 CUDA 运行验证限制。
5. 旧版原理说明清楚标出源码基准和历史行数，不与当前项目定位冲突。
6. 完成静态代码与文档复核，并运行一次新增示例；不运行测试套件。
7. 创建 `docs/dev/PLAN-043-project-purpose-tutorial-OUTCOME.md`，记录实际变更和示例运行结果。
8. 按 `AGENTS.md` 使用中文提交，提交后立即推送。

## 非目标

1. 本轮不新增 PyTorch 算子或兼容 API。
2. 不承诺模型训练性能、全量 API 兼容、CUDA 设备实测或生产用途。
3. 不修改项目包名、代码行数或旧例子实现。
