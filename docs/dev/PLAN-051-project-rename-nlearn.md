# PLAN-051：统一项目名称为 nlearn

## 目标

将项目、Python 包、仓库元数据及所有源码和文档中的项目标识统一为 `nlearn`，并将发行版本更新至 `0.1.0`。

## 范围

1. 将现有 Python 包目录迁移为 `nlearn`，更新内部导入、测试和示例。
2. 将项目标识、环境变量、代码路径、图片路径和文档链接统一改为新名称；PyTorch 官方对照名称保持不变。
3. 更新 `setup.py`、运行时版本、项目说明和仓库地址。
4. 更新主 README 与当前项目目的设计，使公开定位反映独立张量/自动微分实现及 PyTorch 风格 API。
5. 将 GitHub 仓库和本地检出目录改名为 `nlearn`，并更新本地 origin。
6. 以 0.1.0 作为首个新包命名空间版本，记录迁移说明；不保留旧导入命名空间。

## 实施顺序

1. 建立命名设计与本计划。
2. 批量迁移源码文本和相关文件路径，手工核对元数据、入口文档及生成图片。
3. 检查剩余旧名称、导入路径、文档相对链接和 PyTorch 对照代码。
4. 运行全量测试、编译检查和发行包元数据检查。
5. 复核 diff，更新结果文件；将 GitHub 仓库和本地检出目录改名并设置 `origin`。
6. 使用中文提交信息提交计划及结果，然后立即 push。

## 验收标准

- Python 包目录和所有项目导入名为 `nlearn`。
- `setup.py` 和 `nlearn.__version__` 均为 `0.1.0`，发行包名为 `nlearn`。
- 项目文档、示例开关、图片、文件名和链接不残留旧项目标识。
- 官方 PyTorch 对照示例中的 `torch` 导入保持正确。
- 全量测试、编译检查、发行元数据检查通过。
- GitHub 仓库名、本地检出目录及本地 origin 为 `nlearn`；提交后变更已 push。
