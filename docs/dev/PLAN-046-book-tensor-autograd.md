# PLAN-046 编写 Tensor 与自动微分篇

日期：2026-09-29

## 背景

阅读指南和标量自动微分篇已完成。标量节点能解释计算图，但神经网络实际使用多维数组。本篇把数值载体扩展为 NumPy 数组，逐步实现张量前向运算、反向传播和 `Function` 组织方式。

## 目标

1. 写完目录中的第 06 至 10 章，解释 NumPy 数组、Tensor、算子、梯度、广播和归约。
2. 在 `book/代码/02-Tensor与自动微分/` 实现一个仅依赖 NumPy 的小型张量自动微分引擎。
3. 以相同形状的算子梯度为起点，再支持矩阵乘法、广播、求和、均值和形状恢复。
4. 把标量篇的闭包反传整理成 `Tensor` 与 `Function`，并说明和 `torch_1k` 代码的对应关系。
5. 更新书稿目录进度与本任务结果文档。

## 实施范围

- 新增 `book/02-Tensor与自动微分/06-NumPy数组与Tensor.md` 至 `10-组织Tensor和Function.md`。
- 新增 `book/代码/02-Tensor与自动微分/mini_tensor.py` 和对应的 5 个逐章示例脚本及 README。
- 更新 `book/README.md`、`book/目录规划.md`、第二篇 README 和代码目录入口。
- 运行五个示例脚本，核对前向值、梯度、广播还原和训练式标量损失所需操作；不新增测试套件。
- 完成文档与实现复核，创建 OUTCOME，提交并推送。

## 验收标准

1. Tensor 保存 NumPy 数据，并暴露形状、维数、类型和可读转换。
2. 示例展示逐元素加乘、矩阵乘法、重塑、求和与均值的前向值。
3. 自动微分正确累计共享路径梯度；加法和乘法的梯度形状还原到各自输入形状。
4. 矩阵乘法在二维矩阵范围内给出正确梯度；本篇明确列出该限制。
5. `sum`、`mean` 支持全量归约、指定单轴或多轴以及 `keepdims`，其反向结果形状和数值正确。
6. `Function` 按代数逆序执行，Tensor 保存叶节点梯度，并支持 `zero_grad()`。
7. 五个章节脚本均可运行，示例值和梯度与章节推导一致；`git diff --check` 通过。
8. 结果文档记录实际运行命令、结果和范围边界。

## 非目标

1. 本篇不实现完整 PyTorch dtype promotion、设备迁移、索引和高阶导数。
2. `matmul` 示例先限制为二维矩阵，不覆盖向量及批量矩阵乘法。
3. 不修改现有 `torch_1k` API 或依赖。
