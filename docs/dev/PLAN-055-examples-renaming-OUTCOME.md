# PLAN-055 实施结果：示例文件分组重命名

## 实施内容

1. 按计划将 `examples/` 中 40 个 Python 示例重命名为“单数字类别号 + 两位类内序号 + 类别名 + 主题”的格式，分为 8 类。
2. 更新 README、书稿、教程、设计文档、既有计划与结果文档、`torch_protocol/README.md` 和测试中的示例路径，共替换 190 处文件名引用。
3. 将 1 处示例间导入和 4 处测试模块导入改为 `importlib.import_module()`。新文件名以数字开头，不能用于普通 `import` 语句；测试中的脚本路径也已更新。
4. 保留本计划映射表中的旧文件名，作为迁移记录；仓库其他位置不再保留旧文件名引用。

## Review 与检查

- 映射核对：40 个旧文件均唯一映射到新文件；`examples/` 目录实际文件与映射目标完全一致。
- 命名核对：类别号为单数字，类别名与类别号对应；类内序号两位且连续。
- 引用核对：文档中的示例路径均能解析到现存文件；计划映射表之外未发现旧文件名引用。
- 历史 Markdown 文档差异仅替换示例文件名，没有其他内容变化。
- `git diff --check` 与暂存区差异检查通过。
