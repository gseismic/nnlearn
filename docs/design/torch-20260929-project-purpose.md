# torch_1k 项目目的与范围

日期：2026-09-29

## 项目目的

`torch_1k` 是一套可运行、可阅读、可与 PyTorch 对照的训练机制教学实现。它帮助已经会写基础 PyTorch 代码的学习者看懂张量运算如何记录计算图、梯度如何沿图反向传播，以及优化器如何更新参数。

PyTorch 继续承担实际模型开发和训练。`torch_1k` 通过短小明确的 Python 实现，让学习者可以沿着代码理解机制、修改算子，并借助 PyTorch 的结果检查理解是否正确。

## 面向的人群

- 学过基础张量运算和模型训练，希望理解 autograd 内部过程的 Python / PyTorch 学习者。
- 想从简单算子入手，实践前向计算、梯度公式和参数更新的开发者。
- 需要通过小型实现研究张量框架行为边界的读者。

## 项目价值

1. **读得懂**：从 `Tensor`、`Function` 和 `backward()` 跟进动态计算图与梯度传递。
2. **跑得通**：从单个张量运算延伸到模型训练、评估和 checkpoint 的最小闭环。
3. **能对照**：为两边提供相同的数据和初始参数，比较前向结果、梯度和更新结果。
4. **能修改**：读者可以尝试实现或修正算子，再检查前向和反向结果。

## 范围

- 使用 NumPy 实现 CPU 张量运算和自动微分。
- 提供基于 CuPy 的可选 CUDA 路径；具体环境支持以实际依赖和设备测试为准。
- 覆盖教学与小型示例需要的常见 Tensor、autograd、`nn`、优化器、数据加载和状态保存能力。
- 通过精选示例展示 MLP、CNN、Transformer 等训练组件如何连接。

## 明确边界

- 不承诺完整实现 PyTorch API，也不承诺任意 PyTorch 脚本可以直接替换运行。
- 不追求 PyTorch 的训练性能、内存效率或生态兼容性。
- 示例可训练成功只能说明该示例覆盖的链路可运行，不能推导出通用兼容。
- CUDA 是否可运行取决于 CuPy 与 CUDA 环境；未在具备设备的环境完成的路径应明确标注。

## 后续工作判断标准

新增工作应至少满足下列一项，并说明如何验证：

1. 让核心训练机制更容易理解或观察。
2. 让已有教学示例覆盖新的重要机制，并同时核对前向和梯度行为。
3. 修复影响已承诺训练链路的正确性问题。

仅为扩大 API 覆盖面而加入的功能，需要先说明它服务于哪个教学目标或真实示例。项目不以固定代码行数作为目标；应限制功能范围、减少重复实现，并让主要教学路径持续清楚。
