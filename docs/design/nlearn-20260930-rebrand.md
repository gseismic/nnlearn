# nlearn 项目命名与发布接口统一

> 历史状态：本文记录 2026-09-30 的命名决策。项目名称已由 [nnlearn 命名设计](nnlearn-20261001-rebrand.md)取代；当前名称以该设计为准。

日期：2026-09-30

## 决策

项目、Python 发行包和导入包统一使用小写名称 `nlearn`。发布版本统一为 `0.1.0`。仓库定位为独立实现的张量与自动微分框架，提供 PyTorch 风格 API；PyTorch 仍作为可选的对照实现，不是运行时依赖。

## 公开接口

- 安装发行包后使用 `import nlearn`、`import nlearn.nn` 和 `import nlearn.optim`。
- 对照示例使用 `USE_NLEARN` 选择 nlearn 或官方 PyTorch 路径。
- 不保留旧导入名称的兼容包，所有源码、测试、示例、文档和路径统一迁移。
- 版本元数据和运行时 `__version__` 均为 `0.1.0`。

## 兼容和迁移

0.1.0 将发行包和导入命名空间切换为 `nlearn`。使用旧版导入路径的调用方应改为 `nlearn`；基于示例环境变量选择实现的调用方改用 `USE_NLEARN`。函数、类和张量语义不因重命名而改变。

## PyTorch 边界

名称迁移只影响 nlearn 自身标识。代码中以 `torch` 或 `PyTorch` 指官方 PyTorch、比较对象或其风格时继续保留，避免将第三方框架名称错误替换。

## 完成标准

1. 源码目录、导入、发行元数据、运行时版本和项目文档均使用 `nlearn` 与 `0.1.0`。
2. 全仓库不存在旧项目/包标识，PyTorch 对照路径仍然明确且可运行。
3. 测试、示例、构建元数据和重命名后的 GitHub 地址均通过检查。
