# 第一篇配套代码

本篇代码只使用 Python 标准库。每个脚本对应章节中的一步；`scalar_autograd.py` 是第四、五章共用的自动微分实现。

| 章节 | 脚本 | 内容 |
| --- | --- | --- |
| 01 | `01-只保存数值.py` | 包装数值并计算一个神经元的预测与损失 |
| 02 | `02-有限差分.py` | 数值估算导数并更新权重 |
| 03 | `03-计算图.py` | 记录父节点和每条边的局部导数 |
| 04 | `04-反向传播.py`、`scalar_autograd.py` | 沿计算图应用链式法则 |
| 05 | `05-训练单神经元.py`、`scalar_autograd.py` | 用自动微分训练线性神经元 |

从仓库根目录运行，例如：

```bash
python 'book/代码/01-标量自动微分/04-反向传播.py'
```
