# 第二篇配套代码

本篇从 NumPy 数组包装开始，最终在 `mini_tensor.py` 中形成一个小型 Tensor 自动微分引擎。章节脚本只展示当前章节的概念；完整实现包含后续章节逐步介绍的功能。

需要先安装仓库依赖：

```bash
python -m pip install -e .
```

从仓库根目录运行单章示例：

```bash
python 'book/代码/02-Tensor与自动微分/08-张量运算的梯度.py'
```

| 章节 | 脚本 | 关注点 |
| --- | --- | --- |
| 06 | `06-NumPy数组与Tensor.py` | 数据、形状、维数、类型和拷贝 |
| 07 | `07-实现基础张量运算.py` | 逐元素运算、广播、矩阵乘法和重塑 |
| 08 | `08-张量运算的梯度.py` | 加法、乘法和二维矩阵乘法的梯度 |
| 09 | `09-广播归约与梯度累积.py` | 广播梯度还原、sum、mean 和多轴归约 |
| 10 | `10-组织Tensor和Function.py` | 线性预测、均方误差和完整反向传播 |

引擎仅支持稠密 NumPy 数组、浮点梯度、单输出运算和二维矩阵乘法。它用于逐步理解机制，不是 PyTorch 的兼容替代品。
