# D 术语表与问题排查

## 术语表

| 术语 | 含义 |
| --- | --- |
| Tensor | 带形状和数据类型的多维数组对象；在自动微分系统中还可连接计算图 |
| 计算图 | 记录张量运算依赖关系的有向图，反向传播沿图把梯度传回输入 |
| 局部梯度 | 一个运算输出对某个直接输入的导数 |
| 上游梯度 | 从后续运算传回当前节点的梯度 |
| 叶子 Tensor | 当前计算图中没有创建者运算的 Tensor，参数通常是叶子 |
| `requires_grad` | 是否请求自动微分系统跟踪该 Tensor 的运算 |
| `grad` | 反向传播累积到叶子 Tensor 的梯度 |
| `Function` | 将一个前向运算及其反向梯度规则封装为计算图节点 |
| `Parameter` | 默认需要梯度并由模块注册的可训练 Tensor |
| `Module` | 组合参数和子模块、定义模型前向计算的对象 |
| `state_dict` | 用参数名映射到参数数组的模型状态表示 |
| logits | 归一化前的模型分数；交叉熵通常直接接收 logits |
| mini-batch | 一次训练迭代处理的一小组样本 |
| 广播 | 运算时按规则把长度为 `1` 或缺失的轴扩展到兼容形状 |
| Embedding | 用整数索引查询可训练向量表的模块 |
| 注意力 | 用查询与键计算权重，再对值向量做加权汇总的运算 |
| 后端 | 选择数组实现和设备，并负责数组创建、运算分发与数据搬运的层 |
| CUDA | NVIDIA GPU 的并行计算平台；是否能使用还取决于驱动、设备和对应数组库 |

## 常见问题定位

| 现象 | 常见原因 | 建议检查 |
| --- | --- | --- |
| `parameter.grad` 是 `None` | 参数未参与损失计算、未设置 `requires_grad=True`，或整数 Tensor 被设为可训练输入 | 从损失反向追踪计算图；确认模型参数已注册；本书 Tensor 只允许浮点 Tensor 求梯度 |
| 中间结果的 `.grad` 是 `None` | 教学版 `mini_tensor` 只在叶子 Tensor 上累积梯度 | 直接检查输入和参数叶子的梯度；不要假定中间 Tensor 默认保留梯度 |
| 梯度比预期大 | 梯度会在多条路径和多次 `backward()` 间累积 | 每个训练批次开始前调用优化器的 `zero_grad()` |
| 矩阵乘法报形状不匹配 | 左矩阵末轴不等于右矩阵倒数第二轴 | 将 `A:(M,K)`、`B:(K,N)` 写在纸上核对 `K` |
| 偏置梯度形状变成 `(N,D)` | 对广播偏置的梯度没有沿 batch 轴求和 | 对 `gy:(N,D)` 使用 `sum(axis=0)`，恢复 `(D,)` |
| 交叉熵拒绝标签 | 标签形状不是 `(N,)`、不是整数或类别编号越界 | logits 用 `(N,C)`；每条样本的标签是 `0` 到 `C-1` 的整数 |
| loss 变成 `NaN` 或持续上升 | 学习率过大、指数计算不稳定或输入含非有限值 | 先减小学习率；对 softmax/log-sum-exp 使用减最大值的稳定写法；检查输入 |
| sigmoid 在极端输入溢出 | 使用了不稳定的 `1/(1+exp(-x))` 作为唯一计算式 | 对负数改用 `exp(x)/(1+exp(x))`，并核对极大正负输入 |
| 找不到模型参数 | 层或参数没有作为模块属性注册，或只放进普通 Python 容器 | 检查 `named_parameters()`；使用已注册子模块或本书支持的 `Sequential` |
| 恢复检查点时报键名/形状错误 | 保存模型与当前模型结构不同 | 比较 `state_dict()` 键名、层宽和输出类别数 |
| `.to('cuda')` 报设备不可用 | 没有可用 CUDA，或没有与环境匹配的 CuPy | 先运行设备可用性检查；CPU 示例仍可运行 |
| 训练准确率很高但换数据失效 | 示例使用了容易分开的合成数据，或只评估了训练集 | 使用独立验证集和真实任务评估；示例结果不能代替泛化验证 |

## 先检查的训练循环

每个批次按以下顺序执行，最容易发现梯度累计和更新次序问题：

```text
optimizer.zero_grad()
prediction = model(inputs)
loss = loss_fn(prediction, target)
loss.backward()
optimizer.step()
```

`model.eval()` 只切换模块的训练/评估标志；若模型没有依赖该标志的层，前向结果可以不变。本书的最小 MLP 没有 Dropout 或 BatchNorm，因此不能用它演示这些层的评估行为。

## 本书实现范围提醒

书中 `mini_tensor` 和 `mini_nn` 是为了讲清核心机制的短小实现，支持范围小于 PyTorch，也小于仓库完整的 `nnlearn`。例如本书的基础矩阵乘法限二维、CNN 示例使用合成图像、Transformer 示例没有 mask/位置编码，CUDA 运行还要求真实 GPU 与 CuPy。遇到缺失功能时先查看章节“实现边界”，不要把教学代码的限制理解为一般深度学习框架的限制。
