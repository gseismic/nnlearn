# C 形状与广播速查

形状按轴顺序书写，轴编号从 `0` 开始。阅读算子时先写出输入形状，再按规则推导输出形状；张量维数（`ndim`）是轴的数量，元素总数是各轴长度的乘积。

## 常见层的形状

| 运算 | 输入 | 参数或目标 | 输出 |
| --- | --- | --- | --- |
| 标量 | `()` | — | `()` |
| 一批向量 | `(N,D)` | — | `(N,D)` |
| 二维矩阵乘法 | `A:(M,K)`、`B:(K,N)` | 内维 `K` 相同 | `(M,N)` |
| `Linear` | `(N,I)` | `weight:(I,O)`、`bias:(O,)` | `(N,O)` |
| 交叉熵 | logits `(N,C)` | 标签 `(N,)` | 标量 `()` |
| 图像卷积 | 输入 `(N,Cin,H,W)` | 权重 `(Cout,Cin,KH,KW)` | `(N,Cout,OH,OW)` |
| 最大池化 | `(N,C,H,W)` | 窗口 `(KH,KW)`、步幅 `(SH,SW)`、无 padding | `(N,C,OH,OW)` |
| 展平 | `(N,C,H,W)` | 保留 batch 轴 | `(N,C*H*W)` |
| token embedding | id `(N,T)` | 表 `(V,D)` | `(N,T,D)` |
| 多头注意力分数 | Q/K `(N,H,T,Dh)` | 在序列轴相乘 | `(N,H,T,T)` |
| 注意力上下文 | 权重 `(N,H,T,T)`、V `(N,H,T,Dh)` | — | `(N,H,T,Dh)` |

卷积的空间尺寸为：

```text
OH = floor((H + 2*PH - KH) / SH) + 1
OW = floor((W + 2*PW - KW) / SW) + 1
```

无 padding 的最大池化将 `PH=PW=0` 代入同一尺寸公式。本书的 `mini_tensor` 基础矩阵乘法只处理二维数组；注意力示例在自定义 `Function` 内部用 NumPy 批量数组运算。

## 广播判定

从最右侧轴开始对齐形状；缺少的前导轴视为长度 `1`。每一轴上的长度必须相等，或其中一个为 `1`。例如：

```text
(N, D) + (D,)       -> (N, D)
(N, 1) * (N, M)     -> (N, M)
(B, T, D) + (D,)    -> (B, T, D)
```

若某一轴既不相等也没有 `1`，则不能广播，例如 `(2,3)` 与 `(4,3)`。

## 广播梯度还原

前向广播复制了数据，反向要把复制路径的梯度加总到源数据形状：

| 被广播输入形状 | 运算结果形状 | 反向还原 |
| --- | --- | --- |
| `b:(D,)` | `y:(N,D)` | `gb = sum(gy, axis=0)`，结果 `(D,)` |
| `a:(N,1)` | `y:(N,M)` | `ga = sum(gy, axis=1, keepdims=True)`，结果 `(N,1)` |
| `c:(1,D)` | `y:(N,D)` | `gc = sum(gy, axis=0, keepdims=True)`，结果 `(1,D)` |
| `q:(3,1)` | `y:(2,3,4)` | 对前导轴和末轴求和，保留轴后恢复 `(3,1)` |

通用步骤：

1. 若梯度维数多于原输入，先对多出的最左侧轴求和。
2. 对原输入长度为 `1`、梯度长度大于 `1` 的轴求和，并保留该轴。
3. 将结果 reshape 回原输入形状。

## 归约轴与 `keepdims`

对 `x:(2,3,4)`：

| 表达式 | 输出形状 |
| --- | --- |
| `x.sum()` | `()` |
| `x.sum(axis=1)` | `(2,4)` |
| `x.sum(axis=1, keepdims=True)` | `(2,1,4)` |
| `x.mean(axis=(1,2))` | `(2,)` |
| `x.mean(axis=(1,2), keepdims=True)` | `(2,1,1)` |

多轴归约后若需要与原输入广播相乘，保留被约简轴常能减少手动 reshape。
