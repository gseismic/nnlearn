# 18 卷积、池化与 CNN

全连接层把一条样本看成特征向量。图像则有高、宽和通道，卷积层可以在局部区域重复使用同一组权重。本章从二维窗口运算开始，接上最大池化和一个可训练的小型 CNN。

## 图像张量的形状

本书采用 `NCHW` 顺序：批次、通道、高度、宽度。灰度图像的一批数据形状例如 `(36, 1, 12, 12)`。卷积核按输出通道、输入通道、高度、宽度保存，形状为 `(O, C, KH, KW)`。

给定步幅 `(SH, SW)` 和对称填充 `(PH, PW)`，输出空间尺寸为：

```text
OH = floor((H + 2*PH - KH) / SH) + 1
OW = floor((W + 2*PW - KW) / SW) + 1
```

每个输出位置取输入的一个局部窗口，与对应卷积核逐项相乘，再对通道和窗口空间求和。卷积核会在不同位置重复使用，所以它学习的是局部模式，而不是为每个位置单独存一套权重。

## 卷积的反向传播

假设某个输出位置收到梯度 `g`，该窗口对卷积核的梯度贡献是 `输入窗口 * g`；卷积核对输入窗口的梯度贡献是 `卷积核 * g`。多个输出窗口覆盖同一个输入或权重时，要把各处贡献累加。偏置梯度则对批次和输出空间求和。

配套脚本用一个 `2×2` 输入和一个 `2×2` 卷积核展示结果：输出为 `-3`，输入梯度等于该卷积核，卷积核梯度等于输入窗口。

## 最大池化只把梯度交给获胜位置

最大池化在每个窗口中保留最大值，并记住它来自哪个输入位置。反向传播时，该窗口的梯度只加到获胜位置；如果窗口彼此重叠，同一输入可能收到多份贡献。本篇不对池化窗口填充。

`Flatten` 把通道、高度和宽度合并成特征轴，但保留批次轴。这样卷积和池化的输出就能交给已有的 `Linear`。

## 训练一个小型 CNN

运行[配套脚本](../代码/04-进阶模型与运行时/18-卷积池化与CNN.py)：

```bash
python 'book/代码/04-进阶模型与运行时/18-卷积池化与CNN.py'
```

网络依次使用 `Conv2d(1, 4, 3, padding=1)`、ReLU、`MaxPool2d(2)`、`Flatten` 和线性分类层。脚本生成三类不同位置亮块的图像，不下载数据集。固定随机种子下，交叉熵从 `1.130488` 降到 `0.004688`，训练集准确率为 `1.000`。脚本还会打印单窗口卷积与最大池化的输入梯度，便于核对反向传播。

## 实现边界

当前卷积只支持 NCHW 输入、二维正整数步幅和对称填充，不支持分组卷积、dilation 或任意维卷积。最大池化不支持 padding，遇到并列最大值时选择 NumPy `argmax` 返回的第一个位置。实现使用 Python 循环和 NumPy，目的是看清计算过程，不适合大图像训练；合成数据的高准确率也不代表真实图像效果。

## 练习

1. 改变卷积核大小或步幅，手算输出形状并与脚本打印值对照。
2. 让池化窗口彼此重叠，检查反向时梯度是否会累加到同一个输入位置。
3. 将卷积层换成两个连续的卷积层，比较参数数量和分类损失。
