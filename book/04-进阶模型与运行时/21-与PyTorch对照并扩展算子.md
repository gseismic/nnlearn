# 21 与 PyTorch 对照并扩展算子

前面章节逐步实现了张量运算和训练组件。结束这一段实现前，我们用同一组数据和初始参数与 PyTorch 对照，并给基础 `Tensor` 增加一个新的 sigmoid 算子，走一遍从公式到梯度的扩展过程。

## 让对照条件一致

比较两个框架时，要固定输入、目标、参数初值、数据类型、损失归约方式和学习率。否则误差可能来自条件不同，而不是算子实现。

配套脚本构造一个小型线性回归步骤，依次比较预测值、MSE、权重梯度、偏置梯度和一次 SGD 更新。它使用 float64，便于把浮点舍入误差与实现差异区分开。

## 增加稳定的 sigmoid

sigmoid 定义为：

```text
sigmoid(x) = 1 / (1 + exp(-x))
```

直接计算在很大的负数处会让 `exp(-x)` 溢出。对 `x < 0`，可改写为 `exp(x) / (1 + exp(x))`；对非负数仍使用原式。设 `y = sigmoid(x)`，导数可以写成：

```text
dy/dx = y * (1 - y)
```

本章把 `Tensor.sigmoid()` 接入 `Function` 计算图。`mini_nn.Sigmoid` 层仍可用于模型结构；新方法让基础 Tensor 也能直接组合这个算子。

## 运行对照

运行[配套脚本](../代码/04-进阶模型与运行时/21-与PyTorch对照并扩展算子.py)：

```bash
python 'book/代码/04-进阶模型与运行时/21-与PyTorch对照并扩展算子.py'
```

当前环境已安装 PyTorch。线性回归预测、损失、偏置梯度和更新结果完全一致；所有对照项的最大绝对误差为 `1.776e-15`。在 `[-1000, -3, 0, 2, 1000]` 上，sigmoid 前向和梯度与 PyTorch 的最大绝对差都小于 `7e-18`。如果运行环境未安装 PyTorch，脚本会说明并跳过跨框架对照；章节示例不把 PyTorch 加入项目必需依赖。

## 扩展算子的步骤

为计算图添加算子时，可以依次做这些事：

1. 写出前向公式，并检查极端输入下的数值稳定性。
2. 推导每个输入的梯度，并明确保存反向需要的中间值。
3. 在 `Function` 子类中实现前向和反向，再提供 `Tensor` 调用入口。
4. 用已知值检查输出与梯度形状，再用另一个实现或有限差分核对数值。
5. 将算子放进组合表达式，确认梯度能沿整张计算图传回叶子张量。

当前对照只覆盖二维线性回归、MSE、SGD 和 sigmoid，不代表两个框架的整体行为等价。还没有比较高阶梯度、稀疏张量、复杂广播、混合精度或 CUDA 数值。

## 练习

1. 把 sigmoid 改成 ReLU 或 softplus，并实现相应反向梯度。
2. 在 `x=-1000` 与 `x=1000` 附近检查前向是否有限、梯度是否符合极限。
3. 改变学习率和初始参数，比较多个更新步骤中的损失差异。
