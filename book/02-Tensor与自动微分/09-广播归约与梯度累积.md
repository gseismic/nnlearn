# 09 广播归约与梯度累积

前向广播会让不同形状的数组共同参与运算。反向时，梯度必须回到原输入形状：前向被重复使用的值，要把所有对应位置的梯度加起来。

## 把广播梯度还原回输入

设 `A` 的形状是 `(2, 3)`，偏置 `b` 的形状是 `(3,)`，执行 `C = A + b`。前向把 `b` 用在两行上。如果损失是 `C.sum()`，那么 `dL/dC` 是一个全 1 的 `(2, 3)` 矩阵，偏置梯度为：

```text
db = [1, 1, 1] + [1, 1, 1] = [2, 2, 2]
```

`sum_to(gradient, original_shape)` 做两件事：先对比目标多出来的前导轴求和，再对原输入大小为 1、但梯度大小大于 1 的轴求和并保留维度。

## 求和与均值

对输入沿指定轴求和，反向时把输出梯度扩展回被求和前的形状，并沿被归约的位置广播。均值的梯度再除以参与平均的元素个数：

```text
mean(x, axes).backward(g) = broadcast(g) / 归约元素个数
```

本篇支持全量归约、单轴、多轴和 `keepdims=True`。保留维度能让前向结果更容易与原数组对齐；反向仍会恢复到输入形状。

运行[配套脚本](../代码/02-Tensor与自动微分/09-广播归约与梯度累积.py)：

```bash
python 'book/代码/02-Tensor与自动微分/09-广播归约与梯度累积.py'
```

它核对向量偏置和逐行缩放参数的广播梯度，并展示按轴求均值的梯度。

## 梯度为什么要累加

若同一个 Tensor 在计算图中被多次使用，每条路径都对它产生一份梯度。例如 `x*x` 的两条输入边来自同一个 `x`，最终梯度是两份贡献相加。广播只是把这种多路径情况扩展到数组的许多位置。

本书引擎把一次 `backward()` 的所有路径贡献先汇总，再累积到叶子 Tensor 的 `.grad`。再次反传前若要开始新的独立计算，应先调用 `zero_grad()`。

配套脚本还对同一个叶子做了两次反传：第一次从 `x*x` 得到梯度 `4`，第二次从 `3*x` 得到梯度 `3`，所以 `.grad` 累积为 `7`；调用 `zero_grad()` 后它回到 `None`。

脚本的关键输出：

```text
偏置梯度: [2.0, 2.0, 2.0]
逐行缩放参数梯度: [[6.0], [15.0]]
按列均值: [[2.5, 3.5, 4.5]]
均值反向梯度: [[0.5, 0.5, 0.5], [0.5, 0.5, 0.5]]
两次反向后的累积梯度: [7.0]
zero_grad 后: None
多轴归约形状: (1, 3, 1)
多轴求和反向梯度形状: (2, 3, 4)
多轴均值反向梯度首项: 0.125
```

## 练习

1. 对形状 `(2, 3)` 的数组加形状 `(1, 3)` 的数组，推导后一项的梯度形状与数值。
2. 对 `x.mean(axis=0)` 求和后反传，验证每个输入元素的梯度都是 `1 / x.shape[0]`。
3. 把多轴归约 `axis=(0, 2)` 改成 `axis=(2, 0)`，验证结果和梯度不变。
