# 07 实现基础张量运算

有了数组载体后，下一步是让 Tensor 像普通数值一样参与表达式。我们先实现逐元素加法、逐元素乘法、矩阵乘法和形状变换，暂时不记录梯度。

## 逐元素运算和矩阵乘法

`a * b` 表示对应位置相乘，`a @ b` 表示矩阵乘法。它们的含义不同：

```text
a = [[1, 2], [3, 4]]
b = [[2, 0], [1, 2]]

a * b = [[2, 0], [3, 8]]
a @ b = [[4, 4], [10, 8]]
```

逐元素乘法得到 `[[2, 0], [3, 8]]`；矩阵乘法得到 `[[4, 4], [10, 8]]`。本篇先让 `matmul` 处理二维矩阵，向量和批量矩阵规则留给后续扩展。

## 广播与重塑

NumPy 的广播规则让较小数组沿缺失或长度为 1 的轴重复参与前向运算。例如形状 `(2, 2)` 的矩阵加形状 `(2,)` 的向量，会把向量加到矩阵的每一行。广播改变了参与计算的视图，不要求真的复制整份数据。

`reshape` 改变维度组织方式而不改变元素顺序。`(a @ b).reshape(4)` 会把 `2 × 2` 结果展成长度为 4 的向量。第九章会处理这些规则在反向传播时的梯度形状。
