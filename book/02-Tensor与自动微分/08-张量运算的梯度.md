# 08 张量运算的梯度

标量自动微分的链式法则可以直接推广到数组：每条边传递的仍是上游梯度乘以局部导数，只是现在梯度本身也是一个数组。

## 逐元素加法与乘法

若 `z = x + y` 且上游梯度为 `g`，那么：

```text
dz/dx = g
dz/dy = g
```

逐元素乘法 `z = x ⊙ y` 的反向是：

```text
dz/dx = g ⊙ y
dz/dy = g ⊙ x
```

本章先用 `x` 和 `y` 形状相同的例子建立规则，这样每个位置都一一对应。完整引擎还要处理广播；下一章解释如何把广播产生的梯度求和还原。

## 二维矩阵乘法

令 `C = A @ B`，其中 `A` 是 `m × k`，`B` 是 `k × n`，上游梯度 `G` 与 `C` 同形，为 `m × n`。矩阵乘法的梯度为：

```text
dA = G @ B.T
dB = A.T @ G
```

转置让矩阵维度重新对齐。配套示例直接对 `A @ B` 调用 `backward()`，默认上游梯度是全 1；这等价于对矩阵所有元素求和后再反传，可以直接检查两个矩阵收到的梯度。

## 从梯度种子开始

标量损失的初始梯度是 1，因为 `dL/dL = 1`。如果对一个向量结果直接调用 `backward()`，本书实现把每个位置的初始梯度设为 1，这等价于对所有输出元素求和后再反传。也可以显式传入与输出同形的梯度。

运行[配套脚本](../代码/02-Tensor与自动微分/08-张量运算的梯度.py)：

```bash
python 'book/代码/02-Tensor与自动微分/08-张量运算的梯度.py'
```

程序分别打印逐元素乘法和矩阵乘法的前向结果及输入梯度。

矩阵乘法示例的关键输出：

```text
矩阵乘法结果: [[2.0, 6.0], [6.0, 12.0]]
dL/dmatrix: [[2.0, 3.0], [2.0, 3.0]]
dL/dweight: [[4.0, 4.0], [6.0, 6.0]]
```

## 练习

1. 用手算验证 `x=[1, 2]`、`y=[3, 4]` 时 `(x*y).sum()` 对 `x` 的梯度是 `[3, 4]`。
2. 验证矩阵乘法示例中 `dA` 和 `dB` 的形状与原矩阵相同。
3. 用有限差分核对矩阵乘法中 `A[0,0]` 对总和损失的影响。
