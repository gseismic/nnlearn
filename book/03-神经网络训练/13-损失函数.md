# 13 损失函数

模型输出本身不能说明预测得好不好。损失函数把预测值和目标值变成一个标量，训练过程再尝试降低它。

## 均方误差

回归任务常用均方误差：

```text
MSE = mean((prediction - target)²)
```

误差较大的样本会受到平方惩罚。`MSELoss` 在本篇由 `Tensor` 的减法、乘法和均值组合而成，因此梯度沿已有计算图自动返回。

## 交叉熵处理类别预测

分类层输出每个类别的 logits。交叉熵先把它们转换为 log 概率，再取正确类别的负对数概率：

```text
log_softmax(z) = z - log(sum(exp(z)))
loss = -log_softmax(z)[正确类别]
```

直接计算 `exp(z)` 可能溢出。实现先减去每行最大 logit；这个平移不改变 softmax 概率，却能让指数数值稳定。输入标签使用整数类别编号，不需要 one-hot 向量。

运行[配套脚本](../代码/03-神经网络训练/13-损失函数.py)：

```bash
python 'book/代码/03-神经网络训练/13-损失函数.py'
```

默认例子的均方误差是 `0.04`，交叉熵约为 `0.169846`。梯度分别回到预测值和 logits。

## 当前实现范围

本篇 `CrossEntropyLoss` 只接受 `(batch, classes)` logits 和 `(batch,)` 整数标签，按批次取均值。它不处理空间维度、忽略标签、类别权重或标签平滑。

## 练习

1. 计算两个样本的均方误差，并手算对每个预测值的梯度。
2. 将一行 logits 同时加上常数 1000，再比较损失和梯度是否基本不变。
3. 如果模型把正确类别的 logit 提高、其他 logits 不变，交叉熵会怎样变化？
