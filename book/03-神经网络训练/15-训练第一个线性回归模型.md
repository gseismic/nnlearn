# 15 训练第一个线性回归模型

现在把 `Linear`、`MSELoss`、自动微分和 SGD 连成一次完整训练。我们生成满足 `y = 3x - 1.5` 的小型数据，并加上少量噪声，让模型从样本中估计权重和偏置。

## 全批次训练

本章先把全部 100 个样本放进一次前向计算。每轮训练按以下顺序执行：

1. 清理模型参数梯度。
2. 计算 `prediction = model(inputs)`。
3. 计算预测与目标之间的均方误差。
4. 调用 `loss.backward()`。
5. 调用 `optimizer.step()` 更新权重和偏置。

运行[配套脚本](../代码/03-神经网络训练/15-训练第一个线性回归模型.py)：

```bash
python 'book/代码/03-神经网络训练/15-训练第一个线性回归模型.py'
```

固定随机种子后，均方误差从约 `4.9235` 降至约 `0.0004`，权重接近 `3`，偏置接近 `-1.5`。最终损失不会降到零，因为目标中加入了噪声。

## 观察训练过程

输入范围和噪声大小会影响估计。可打印每轮损失，也可在更新前后检查参数。若损失发散，先减小学习率；若损失持续下降但很慢，可适当增大学习率或增加训练轮数。

## 练习

1. 把真实函数改成 `y=-2x+0.7`，检查模型是否学到新的参数。
2. 去掉噪声，观察最终误差。
3. 将全部样本复制两遍，比较全批次平均损失是否改变。
