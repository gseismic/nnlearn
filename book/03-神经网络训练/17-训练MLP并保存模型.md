# 17 训练 MLP 并保存模型

前面已经把训练组件分别跑通。本章把它们组合成一个多层感知机（MLP），在三类二维合成数据上完成分类，并保存和恢复模型参数。

## 从特征到 logits

模型由 `Linear(2, 12)`、ReLU 和 `Linear(12, 3)` 组成。最后一层输出 3 个 logits，不需要手动先做 softmax；`CrossEntropyLoss` 会以数值稳定的方式计算正确类别的损失。

训练时，DataLoader 每次提供一批特征和整数标签。每个批次执行清梯度、前向、交叉熵、反向和 SGD 更新。评估时调用 `model.eval()`，得到 logits 后取最大值所在的类别。

本篇没有 Dropout 或 BatchNorm，所以 `eval()` 只切换模块标志，不改变这个 MLP 的计算结果。带有训练/评估行为差异的层会在进阶实现中再讨论。

## 保存并恢复参数

`state_dict()` 按模块路径返回参数副本，例如 `network.layer_0.weight`。配套脚本用 NumPy NPZ 文件保存这些数组，再载入一个新模型。载入后用相同输入计算 logits，并比较最大绝对差值。

运行[配套脚本](../代码/03-神经网络训练/17-训练MLP并保存模型.py)：

```bash
python 'book/代码/03-神经网络训练/17-训练MLP并保存模型.py'
```

固定种子下，训练损失持续下降，合成测试集准确率达到 `1.000`；载入检查点后的 logits 最大差值为 `0`。这是一个容易分开的合成数据集，只说明本示例的训练与存取链路工作，不代表对其他数据集的泛化能力。

## 练习

1. 改变隐藏层宽度和学习率，比较损失与测试准确率。
2. 保存模型后，把模型参数改成零，再载入检查点，验证输出恢复。
3. 增加训练样本噪声或让类别中心更接近，观察准确率如何变化。
