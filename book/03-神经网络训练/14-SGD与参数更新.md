# 14 SGD 与参数更新

反向传播把梯度写入参数。优化器根据这些梯度修改参数数据。最简单的随机梯度下降（SGD）更新规则是：

```text
parameter = parameter - learning_rate × parameter.grad
```

学习率控制步长。它太大时可能越过低损失区域，太小时会收敛得慢。配套实现只保留最基础的 SGD，不包含动量、权重衰减或参数组。

## 一次完整更新

对一个参数 `weight=1` 和目标 `5`，均方误差梯度是 `-8`。学习率 `0.1` 会把参数更新到 `1.8`，损失从 `16` 降到 `10.24`。

```python
optimizer.zero_grad()
loss = loss_fn(model_output, target)
loss.backward()
optimizer.step()
```

先清理上一步梯度，再构建损失图、反向传播，最后调用 `step()`。忘记清梯度会让 `.grad` 累积多步结果，参数更新就不再是当前批次的梯度。

运行[配套脚本](../代码/03-神经网络训练/14-SGD与参数更新.py)：

```bash

```

## 练习

1. 把学习率改成 `0.5`，手算参数更新后的损失。
2. 连续执行两次 `backward()`，观察梯度累积；在第二步前调用 `zero_grad()`，比较结果。
3. 若参数没有梯度，优化器为什么应该跳过它？

## 对应到仓库
