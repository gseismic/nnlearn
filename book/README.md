# 《自己动手实现 PyTorch》

这本书会从一个数字和它的导数开始，循序渐进地实现一个小型深度学习框架：先理解计算图与反向传播，再构建多维 Tensor，最后连成模型训练流程。

本书配合仓库中的 `nnlearn` 阅读和对照。目标是让读者看懂训练机制并能修改实现；它不以复刻完整 PyTorch API 或追求训练性能为目标。
