# 01 环境与运行代码

前几章只使用 Python 标准库，不需要先安装 PyTorch、NumPy 或其他第三方包。后面开始构建数组 Tensor 时，再安装本仓库依赖。

## 检查 Python

在仓库根目录运行：

```bash
python --version
```

仓库 `setup.py` 声明 Python 3 为最低要求。若你的系统中 `python` 指向 Python 2，请把下面命令中的 `python` 换成 `python3`。

## 安装本仓库

进入仓库根目录后执行：

```bash
python -m pip install -e .
```

这会安装 `nnlearn` 运行所需的 NumPy 和日志依赖。CUDA 使用 CuPy，是可选路径；本书前半部分不需要 CUDA。

## 运行章节代码

从仓库根目录运行脚本，例如：

```bash
python 'book/代码/01-标量自动微分/01-只保存数值.py'
```

文件名中的空格或非 ASCII 字符在不同终端中可能需要引号。命令输出是章节推导的可执行版本；如果改了代码，输出自然也会变化。

## 运行结果和检查方法

章节会展示关键输出。遇到梯度时，先用手算或有限差分做一个简单核对，再继续添加功能。使用 PyTorch 的章节会注明它是额外的参考依赖；其他章节不应因为没有安装 PyTorch 而无法运行。

## 推荐的阅读习惯

1. 一次只改一个算子或一条梯度公式。
2. 用很小的输入，例如标量或 `2 × 2` 矩阵，打印中间值和形状。
3. 出现不一致时，先检查输入、输出和梯度的形状，再检查求导公式。
4. 记录你运行的命令和环境；CUDA 结果还取决于 CuPy、驱动和设备。
