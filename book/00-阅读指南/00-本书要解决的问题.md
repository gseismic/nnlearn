# 00 本书要解决的问题

PyTorch 让我们可以用几行代码搭起模型、计算损失并更新参数。模型越大，越容易只记住“调用 `backward()`”，却说不清梯度从哪里来、为什么参数会朝某个方向变化。

本书从最小的计算开始，逐步实现这些机制。我们会先处理一个普通数字，再让它记录自己参与过的运算；接着把单个数字扩展成多维 Tensor，最后把 Tensor、神经网络层、损失、优化器和数据加载器连成一个训练过程。

## 读完后希望你能做到什么

- 沿着一次前向计算画出计算图，解释反向传播怎样使用链式法则。
- 为加法、乘法、矩阵乘法等算子推导并实现梯度。
- 理解 `Tensor`、`Parameter`、`Module`、损失函数和优化器各自承担的工作。
- 训练一个小模型，并用有限差分或 PyTorch 对照关键数值。
- 阅读并修改仓库中的 `nnlearn` 实现，知道它做了什么以及没有做什么。

## 本书会实现什么

本书的目标是一个规模受控、便于阅读的小型教学框架。它从 CPU 和基础算子开始，重点放在张量计算、反向模式自动微分与模型训练。进阶章节再介绍卷积、注意力和可选 CUDA 后端。

小型教学框架无法覆盖 PyTorch 的完整 API，也不会达到 PyTorch 的性能、内存管理能力或生态范围。本书会把 PyTorch 用作参考和数值对照工具，不把自行实现的代码称为 PyTorch 的替代品。

## 需要哪些基础

读者需要会读写基本 Python 程序，了解变量、函数、列表、循环和类。进入 Tensor 部分前会介绍必要的 NumPy 用法；阅读自动微分篇不要求先学过微积分，我们会先用有限差分观察“输入变化一点，输出变化多少”，再引入导数和链式法则。

本书不会从 Python 语法零基础讲起。如果某个 Python 特性第一次出现，章节会在它影响实现理解时作简短说明。

## 怎么读

建议按章节顺序推进。每章先运行代码，再沿着一个具体数值手算一次，之后阅读实现并修改一个小地方。代码会保存在 `book/代码/`，最终机制再映射到 `nnlearn/` 对应模块。
