# 01 从一个数字开始

神经网络训练可以先缩小到一个问题：给定输入 `x`，调整参数 `w` 和 `b`，让预测值 `w × x + b` 接近目标值。

本章先不求导，也不建计算图。我们只让 Python 把一次预测和损失算出来，再观察普通数字为什么还不够支持自动微分。

## 一次最小的预测

取输入 `x = 2`，目标 `y = 5`，初始权重 `w = 1`、偏置 `b = 0`：

```text
预测值 = w × x + b = 1 × 2 + 0 = 2
误差   = 预测值 - 目标值 = 2 - 5 = -3
损失   = 误差² = 9
```

如果损失更小，预测通常更接近目标。我们希望调整 `w` 和 `b`，让损失下降。后面会让程序算出调整方向；本章先把这条计算过程写清楚。

## 把数值包进一个对象

Python 的 `float` 只保存数值，例如 `2.0`。接下来的章节会给它增加梯度和计算来源，所以我们先写一个极小的 `Value` 类：对象保存数值，重载加法、减法和乘法，使表达式仍然好读。

运行配套代码：

```bash
python 'book/代码/01-标量自动微分/01-只保存数值.py'
```

```python
x = Value(2)
target = Value(5)
weight = Value(1)
bias = Value(0)

prediction = weight * x + bias
error = prediction - target
loss = error * error
```

输出应为预测值 `2`、误差 `-3`、损失 `9`。此时 `Value` 仅包装普通浮点数；它没有计算梯度，也不知道 `loss` 是经过哪些运算得到的。

## 表达式背后的对象

表达式 `weight * x + bias` 由两次 Python 运算组成。第一次乘法创建一个新的 `Value`，随后加法再创建另一个 `Value`。如果只保存每一步的结果，最终损失是 `9`，但中间对象并没有记录自己来自哪个输入。

因此，仅重载运算符还不是自动微分。我们还需要回答两个问题：

1. 输入稍微变化时，损失会怎样变化？
2. 能否让每个结果记住产生它的输入和运算？

下一章用有限差分观察第一个问题；第三章开始记录第二个问题所需的信息。

## 练习

1. 把目标改成 `3`，手算预测、误差和平方损失，再运行程序核对。
2. 把损失改成绝对误差。需要给 `Value` 增加什么运算？
3. 用 `float` 重写同一段计算。比较两种写法的结果，并说明当前 `Value` 多做了什么、还缺少什么。

## 对应到仓库

当前仓库的 `torch_1k` 没有单独的标量 `Value` 类；它直接以 NumPy 数组承载 `Tensor` 数据。这里的包装类是为了从最小概念出发，后续会把它扩展为记录计算图的标量节点。
