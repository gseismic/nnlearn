# 02 导数到底表示什么

上一章算出了损失 `9`，但还不知道该把权重调大还是调小。导数回答的是一个局部问题：输入变化一小点时，函数输出大约变化多少。

## 先用斜率理解导数

对函数 `f(x)`，在 `x` 附近取一个很小的 `ε`，比较 `f(x + ε)` 和 `f(x - ε)`：

```text
f'(x) ≈ [f(x + ε) - f(x - ε)] / (2ε)
```

这是中心有限差分。`ε` 越小通常越接近局部斜率，但过小会受到浮点数舍入影响，因此它适合观察和核对，不适合替代所有训练中的求导。

例如 `f(x) = x³ + 2x`，在 `x = 2` 时解析导数是 `3x² + 2 = 14`。配套代码用几个 `ε` 估算这个斜率。

## 用损失斜率更新权重

沿用上一章的数据：`x = 2`、目标 `5`、偏置 `0`。把权重记作 `w`，损失为：

```text
L(w) = (w × 2 - 5)²
```

在 `w = 1` 处，损失为 `9`。手算可得 `dL/dw = 2 × (2w - 5) × 2`，所以该点的导数是 `-12`。负号表示小幅增加权重会让损失下降。若学习率取 `0.1`：

```text
w_new = w - 学习率 × dL/dw = 1 - 0.1 × (-12) = 2.2
```

新预测是 `4.4`，新损失是 `0.36`。一步更新已经让预测接近目标。

运行代码：

```bash
python 'book/代码/01-标量自动微分/02-有限差分.py'
```

它会同时计算一个通用函数的数值斜率，并用有限差分估算上面的权重梯度。

一次运行的关键输出如下：

```text
epsilon=0.1, 导数估计=14.010000
epsilon=0.01, 导数估计=14.000100
epsilon=0.0001, 导数估计=14.000000
更新前: weight=1.000000, loss=9.000000
有限差分梯度: dL/dw=-12.000000
更新后: weight=2.200000, loss=0.360000
```

## 有限差分的边界

有限差分需要重复执行函数。若参数有一百万个，每个参数都单独扰动一次会非常昂贵；选错 `ε` 也会导致估计不准。神经网络实际使用链式法则，把每个运算的局部导数组合起来一次性计算梯度。

有限差分仍然很有用：我们可以用它抽查自动微分实现是否正确。下一章先让结果记住运算和局部导数，之后就能沿这条记录应用链式法则。

## 练习

1. 把 `ε` 从 `1e-1` 改成 `1e-2`、`1e-4`，观察误差怎样变化。
2. 手算 `L(w) = (3w - 1)²` 在 `w = 0` 处的导数，再用有限差分核对。
3. 按照本章更新公式再走一步，检查损失是否继续下降。
