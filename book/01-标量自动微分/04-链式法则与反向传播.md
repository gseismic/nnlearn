# 04 链式法则与反向传播

第三章已经为每条边记录了局部导数。现在把它们组合起来，求每个输入对最终结果的导数。

## 链式法则

若 `z` 依赖 `y`，而 `y` 又依赖 `x`，那么：

```text
dz/dx = dz/dy × dy/dx
```

对一张计算图，从最终节点开始设置 `dL/dL = 1`。沿边向输入传播时，把当前梯度乘以边上的局部导数；若一个节点收到多条路径的梯度，就把它们相加。

例如 `f(x) = x² + 3x`，在 `x = 2` 时：

```text
df/dx = 2x + 3 = 7
```

程序会让两个乘法分支都向同一个 `x` 累积梯度，得到相同结果。

## 反向拓扑顺序

一个节点的梯度只有在所有后继节点都处理完后才完整。因此先从结果递归访问父节点，得到拓扑顺序，再反向遍历。代码中的 `backward()` 分成两步：

1. 找出当前结果可达的节点，并把它们的梯度清零。
2. 给结果梯度设为 `1`，逆序调用每个节点保存的反向规则。

这里每次调用会重算这张图的梯度。参数梯度不会跨调用自动累加；需要多个样本一起训练时，先把样本损失合成一个总损失，再调用一次 `backward()`。后续 Tensor 章节会再讨论框架常见的梯度累积接口。

## 运行配套实现

```bash
python 'book/代码/01-标量自动微分/04-反向传播.py'
```

示例先计算 `x² + 3x`，再计算一个平方损失对权重和偏置的梯度。后者沿用前几章的数据：`x=2`、`w=1`、`b=0`、目标为 `5`，损失为 `9`，因此 `dL/dw=-12`、`dL/db=-6`。

程序输出：

```text
x^2 + 3x = 10
d(x^2 + 3x)/dx = 7

loss = 9
dL/dw = -12
dL/db = -6
```
