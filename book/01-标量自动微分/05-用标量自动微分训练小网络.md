# 05 用标量自动微分训练小网络

现在已经可以计算一张标量计算图中每个输入的梯度。把它用于训练时，只需要循环执行四件事：前向计算、计算损失、反向传播、沿负梯度方向更新参数。

## 最小神经网络：一个线性神经元

一个线性神经元的输出是：

```text
prediction = weight × input + bias
```

虽然只有一个神经元，它已经包含参数、前向计算、损失和梯度更新这些训练的基本环节。我们用五个样本拟合 `y = 2x + 1`，以均方误差作为目标：

```text
loss = [Σ (prediction_i - target_i)²] / 样本数
```

## 训练循环

配套脚本在每一轮都用当前 `weight` 和 `bias` 创建一张新的计算图。它先把所有样本损失相加，只对平均损失调用一次 `backward()`，然后更新两个参数：

```python
loss.backward()
weight.data -= learning_rate * weight.grad
bias.data -= learning_rate * bias.grad
```

这里直接改变 `.data`，不会把参数更新本身再记录进计算图。这个教学实现每次反向传播都会清理本图节点的梯度，因此把所有样本先合并为一个损失很重要。

运行程序：

```bash
python 'book/代码/01-标量自动微分/05-训练单神经元.py'
```

程序会打印第 0、10、50 和 100 轮的均方误差，以及最后学到的权重和偏置。由于目标函数正好是线性的，训练结果应接近 `weight=2`、`bias=1`；学习率、轮数或初始值改变后，数值也会改变。

在默认参数下，关键输出是：

```text
step=  0 loss=9.00000000 weight=0.000000 bias=0.000000
step= 10 loss=0.21381037 weight=1.785252 bias=0.651322
step= 50 loss=0.00002656 weight=1.999971 bias=0.994846
step=100 loss=0.00000000 weight=2.000000 bias=0.999973
```

## 从代码看四个步骤

1. **前向计算**：对每个输入调用 `weight * x + bias`。
2. **计算损失**：把预测和目标之间的误差平方并求平均。
3. **反向传播**：从平均损失出发，沿计算图累计 `dL/dweight` 和 `dL/dbias`。
4. **更新参数**：使用 `parameter -= learning_rate * gradient`。

学习率控制每次更新的步长。太大可能越过低损失区域，太小则会让训练变慢。这里的例子数据少、模型简单，可以直接观察每个参数和损失；后面的 Tensor 章节会把同一套过程扩展到数组。

## 练习

1. 把目标改为 `y = -x + 0.5`，训练后检查参数是否接近 `-1` 和 `0.5`。
2. 把学习率改成 `0.5`，观察损失变化。再改成 `0.001`，比较收敛速度。
3. 把平方误差换成绝对误差。先写出 `|e|` 对 `e` 的分段导数，再考虑在 `e=0` 处如何定义。
4. 让一个训练步骤只使用一个样本，并在反向前把各样本梯度累加起来。比较它和先合并损失再反传的结果。

## 对应到仓库

`nlearn` 中同一训练链路由 `Tensor.backward()`、`nn.Linear`、损失模块和 `optim.SGD` 等组件完成。本章用纯 Python 标量把链路拆开；下一篇会把数值载体从一个 `float` 扩展成 NumPy 数组。
